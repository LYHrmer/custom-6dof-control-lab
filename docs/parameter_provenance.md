# 参数来源与模型修订

这个项目目前验证的是六轴机械臂的自由空间数值模型和控制接口。模型能编译、控制测试通过，不等于质量分布、传动系统或实物安全范围已经验证。下面将保留的导出值、计算结果、仿真假设和硬件未知项分别记录；具体运行以对应版本的模型清单和实验配置哈希为准。

## 来源类别

| 标记 | 含义 | 使用方式 |
|---|---|---|
| `source` 原始来源 | 可追溯到保留的原始文件、固定上游提交，或用户陈述 | 写清出处；文件里存在某个值，不代表它已由实物验证 |
| `derived` 计算或修正 | 能从所列输入和算法重算，有证据支撑 | 保留公式、坐标定义和生成版本；不把计算需求当成电机能力 |
| `assumption` 仿真假设 | 为本次数值实验明确选择的配置 | 只约束仿真；调整时更新版本或实验记录 |
| `hardware_unknown` 硬件未知 | 缺少型号细节、手册定义、CAD核验或实测 | 在配置中保留 `null`，后续获得证据后再填；不用经验值冒充标定 |

## 模型参数

| 参数 | 类别与来源 | 当前值或处理 | 限制 |
|---|---|---|---|
| 运动链、关节 origin/axis | `source`：原始 URDF | 6 个转动关节 `Joint1`–`Joint6`；1 个固定 `Joint_tool` | 尚未核对实物零位、正方向与装配尺寸 |
| 连杆质量、质心和惯量 | `source`：原始 URDF；逐项核对导出 CSV | 除重复的 `Link_tool` 物理属性外保留原值；惯量使用原 URDF 符号 | 数学合法性检查通过，材料、分布和积惯量约定仍未物理核验 |
| 去除重复末端 | `derived`：CSV 同一 CAD 实例、变换后几何/质心重合 | 保留一份 `Link6`；删除 `Link_tool` 的重复质量/惯量和几何，保留固定工具框架 | 每份质量为 0.0427877844573265 kg；不是把两份质量合并 |
| 修正后质量 | `derived`：原始质量求和减去一份重复末端 | 总质量约 4.3897532198 kg；活动部分约 2.3623211643 kg | 这些是模型质量，不是称重记录 |
| 积惯量反号诊断 | `derived`：两份重复零件惯量转到同一轴方向比较 | 当前相对差 23.7235%；只作诊断的双侧非对角元反号使差降至约 3.85×10⁻⁷ | 没有因此对任意连杆反号；待 CAD/导出器核验 |
| 工具坐标 | `source`：原始 `Joint_tool` | 相对 `Link6` 平移 `[0,0,0.03275]` m，RPY `[0,0.10415,-0.68068]` rad；`tool_site` 位于该框架原点 | 它是导出工具框架，不是经过标定的实际接触 TCP |
| 模型长度单位 | `source`：URDF 米制约定；STL 与该坐标链一致解释 | 使用 m | STL 没有可靠单位声明；尚未量测实物验证尺度 |
| 视觉网格 | `source`：保留的 processed/meshes/visual | 使用处理后网格；只用于渲染 | 简化来源不是精度认证；不作为接触验证依据 |
| 接触与自碰撞 | `assumption`：第一阶段自由空间任务范围 | 所有碰撞关闭，地面也仅显示 | 不验证真实碰撞、叉形工具空腔、夹持或接触任务 |
| 关节范围 | `source` 原导出值；作为 `assumption` 用于数值约束 | 各轴 ±3.14 rad | 不是已验证机械止点；不能作为实物限位 |
| 原始 velocity / effort | `source`：原始 URDF | 每轴 1 rad/s、100 N·m，保留在审计记录 | 不用作实物能力；URDF velocity 也不是 MuJoCo 自动执行的速度限制器 |
| 处理后 effort / dynamics | `source`：processed URDF | effort 为 `[1.3,7.9,2.4,0.8,0.7,0.5]` N·m；damping=0.1，friction=0.05 | 只记录差异，派生 MJCF 不沿用这些推算/补充值；7.9 N·m 不是 DM4310 额定值 |
| 被动阻尼、摩擦、armature | `assumption`：理想化模型 | MJCF 中均为 0 | 0 表示本阶段省略该效应，不表示实测为零 |

完整几何距离、主惯性矩、网格面数、源哈希与原始/处理后差异见 [模型审计记录](model_audit_notes.md) 和 `reports/model_audit.json`。

## 数值控制配置

参数入口为 `configs/simulation.json`。下表记录第一阶段配置的含义，禁止将该表作为电机配置直接下发实物。

| 参数 | 类别与依据 | 当前数值 | 解释 |
|---|---|---|---|
| 仿真步长 | `assumption`：数值积分选择 | 0.001 s；MuJoCo `implicitfast` | 尚未对应真实总线时序、抖动或延迟 |
| 重力 | `assumption`：标准数值环境 | `[0,0,-9.81]` m/s² | 没有辨识底座实际安装方向 |
| 执行器 | `assumption`：理想直接关节力矩输入 | 6 个 `motor`，gear=1，各轴限幅 ±10 N·m | 这是数值实验包络，既不是减速比，也不是 DM4310 输出能力 |
| 平移刚度/阻尼 | `assumption`：低速小位移任务配置 | 每方向 40 N/m、8 N·s/m | 未复用 Panda 任务力或默认增益；尚无实物整定 |
| 旋转刚度/阻尼 | `assumption`：低速小角度任务配置 | 每方向 0.3 N·m/rad、0.05 N·m·s/rad | 与平移参数分开设置 |
| 指令关节阻尼 | `assumption`：控制器中的 `-D qdot` | `[0.03,0.03,0.06,0.008,0.005,0.002]` N·m·s/rad | 属于控制指令，不是 CAD 或电机的被动摩擦；第三轴本轮数值整定提高至 0.06 |
| 重力补偿 | `derived`：保留惯性参数和当前姿态 | 用同一模型、零速度下的重力项；另以 URDF 势能/质心 Jacobian 计算交叉核对 | 同模型的静态保持只能验证实现一致性，不能证明实物补偿准确 |
| 轨迹 | `assumption`：最小控制测试 | 世界 x 方向 2 mm，世界 z 方向旋转 0.01 rad；4 s 五次平滑过渡，总时长 10 s | 只覆盖起始姿态附近的小幅运动，不代表全工作空间能力 |
| 低速验收阈值 | `assumption`：本次数值验收 | 最大关节速度 <0.15 rad/s；要求无力矩限幅 | 是测试阈值，不是实物速度上限 |
| 奇异性诊断尺度 | `assumption`：使空间 Jacobian 数值可比较 | 控制实验将平移三行除以 0.3 m | 条件数依赖该尺度，不能与其他尺度的值直接比较 |

六维向量统一采用世界坐标，在 `tool_site` 原点定义；wrench 顺序为 `[Fx,Fy,Fz,Tx,Ty,Tz]`，速度为 `[vx,vy,vz,wx,wy,wz]`。关节力矩计算为 `tau = J.T @ wrench + gravity - D @ qdot`，之后按仿真执行器限幅。六轴关节和传感器按名称映射，不假设上游七轴数组布局。

## 姿态修订与版本记录

原始零位接近奇异，不用于控制初姿。`tool4_v1` 先使用 `[0.3,-0.7,0.8,0.4,-0.5,0.2]` rad，六维 Jacobian 满秩，但按 0.3 m 缩放后条件数约 **133.16**。首版保留，后续修改通过新模型版本记录。

本轮 `tool4_v2` 姿态修订采用 `[0.7,-0.4,-1.23,0.04,0.22,-0.34]` rad。候选来自固定随机种子 **60912** 的 **1000** 个数值构型，依据奇异值与工具高度选择后取整。对取整姿态重新做 URDF 运动学计算，按同一 0.3 m 缩放的最小奇异值约 **0.19803232**，条件数约 **10.38303**，工具原点世界 z 坐标约 **0.15242859 m**。

这是改善数值实验条件的姿态选择，未进行真实自碰撞或机械止点验证，也不是实物启动姿态。高于底座坐标平面不能证明没有碰撞。审计报告对原始零位采用的是 0.1 m 缩放，两份报告已各自注明尺度，应先统一尺度再比较条件数。

模型版本内容见 `models/<model_version>/scene.xml` 与 `manifest.json`。清单记录 URDF、视觉网格、生成脚本、配置及生成场景的 SHA-256，同时记录 MuJoCo 版本、自由度、执行器/传感器数量和初始重力项。输入位于 `inputs/` 并保留原始压缩包；改结构时新增输入/模型版本，重新跑审计和接口测试，不通过覆盖旧模型掩盖参数变化。

## 算法来源与支持范围

| 内容 | 类别与来源 | 本阶段使用方式 |
|---|---|---|
| 上游算法版本 | `source`：`/home/lyh/robot-arm-compliant-control-lab` 固定提交 `7aec01379ff9a8b135cbac75f18102eb9a27ea8f` | 读取固定 Git 对象，不使用正在变化的工作区文件；原项目本阶段只读 |
| 最小依赖 wheel | `derived`：`tools/build_upstream_wheel.py` | 仅取未修改的 `__init__.py`、`controllers.py`、`franka_control.py`，附许可证和来源清单；`dependencies/upstream-lock.json` 记录源码及 wheel 哈希 |
| 六轴适配器 | `derived`：`src/custom6dof/adapter.py` | 使用上游六维 wrench 阻抗接口，单独建立六轴 Jacobian、力矩映射、工具坐标和限幅 |
| 其他上游类 | `source`：所选模块内保留的原代码 | 模块内存在某个七轴或其他控制器类不等于本项目支持它；当前验收范围为六轴重力补偿和低速阻抗 |
| 暂不支持项 | 范围约束 | 不迁移 BC/PPO 权重、七轴 C++ 实现或七轴零空间姿态项；未完成导纳/混合控制及实物外力估计；不声称强化学习更优 |

wheel 是固定源码生成的依赖制品，不是第二套独立维护的算法仓库。今后若需升级，应选择新的明确提交、重新生成来源清单并重跑六轴测试，不直接编辑已安装的上游模块。

## 观测和评价数据

| 数据 | 类别与入口 | 能说明什么 |
|---|---|---|
| 仿真关节位置、速度 | `derived`：MuJoCo `jointpos` / `jointvel` | 是仿真状态观测，不包含实物编码器误差或总线延迟 |
| `sim_actuator_tau_*` | `derived`：MuJoCo `actuatorfrc` | 是理想执行器输出力矩；不代表真实电机的反馈定义，更不代表外部力矩 |
| `normal_force=0` | `assumption`：上游状态接口兼容占位 | 当前阻抗控制不用该字段；0 不是无接触的测量结论 |
| `eval_external_tau_*` | `assumption`：已知仿真扰动，仅评价记录 | 控制器不接收这组真值；注入的关节扰动也未宣称等于某个末端 wrench |
| `external_wrench_observation` / `estimated_external_wrench` | `hardware_unknown` / 尚未实现 | 当前为 `null`；没有外力传感或外力估计能力的交付声明 |

未来力矩残差或外力估计应增加独立字段，不能复用评价真值冒充观测。验证估计器时可以用仿真真值评分，但读取真值的控制器不能被称作无传感器实物方案。

## 等待硬件或 CAD 证据的项目

入口为 `configs/hardware_unknowns.json`。用户已确认现有电机是 **达妙 4310**、可以反馈力矩，当前没有额外末端力/力矩传感器。这是用户提供的现物信息；项目尚未读铭牌、连接总线或运行电机。

| 待确认项 | 当前记录 | 所需证据 |
|---|---|---|
| 反馈力矩定义与单位 | `hardware_unknown`：`null` | 精确型号/固件的通信定义；确认反馈是电流换算值、指令值还是其他定义，以及量纲/符号 |
| 反馈位于电机侧或输出侧 | `hardware_unknown`：`null` | 手册定义、每关节传动结构/减速比和静态数据核对；本阶段不做堵转实验 |
| 控制模式与固件 | `hardware_unknown`：`null` | 精确固件版本、控制模式和命令单位；不要从接口名字推断 |
| 连续/峰值力矩与热限制 | `hardware_unknown`：`null` | 对应型号/供电/散热条件的额定资料，峰值持续时间及保护条件 |
| 编码器方向、零点和机械限位 | `hardware_unknown`：`null` | 每关节安装、编码器与机械止点对应记录；与 URDF 轴方向逐轴核对 |
| 物理速度范围和总线时序 | `hardware_unknown`：速度项为 `null`，时序未验证 | 电机资料与后续只读日志；仿真步长不能替代测量 |
| CAD/BOM 与实际质量分布 | `hardware_unknown`：`null` | CAD 导出组件名还出现 J4340，需核对装配体与现物 4310 的关系；称重、零件归属及质心证据 |
| 积惯量约定 | `hardware_unknown`：`null` | 原 CAD 质量属性、坐标系定义与导出器变换代码或可靠重导出对照 |
| 实际工具 TCP 与负载 | `hardware_unknown`：`null` | 工具几何/安装测量、末端负载与后续标定记录 |

结构重新设计后，这些参数仍需按新版本重新核实。当前 `hardware_execution_enabled=false`；第一阶段结果不授权电机使能或实物控制。
