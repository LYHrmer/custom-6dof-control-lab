# 模型审计记录

结论来自保留的原始 URDF、导出 CSV、原始 STL 与处理后 URDF 的重新计算，未把 Claude 建议文档的结论当作事实。机器可复现结果在 `reports/model_audit.json`，入口为 `src/custom6dof/audit.py`。审计只读取输入，报告包含源文件 SHA-256、逐项参数差异及每个 STL 的三角面数。

安装项目后，在项目根目录运行：

```bash
rtk proxy .venv/bin/python -I -m custom6dof.audit --output reports/model_audit.json
rtk proxy .venv/bin/python -I -m pytest tests/test_audit.py -q
```

审计不会改写 CAD 导出，也不会连接电机。测试覆盖坐标旋转顺序、非物理惯量、损坏 STL、闭环/重复父节点、伪重复几何及真实 MuJoCo 导入差异。

## 末端重复的证据

CSV 的 `SW Components` 字段中，`Link6` 与 `Link_tool` 都引用 `打印件-末端-1`。两者各有质量 **0.0427877844573265 kg**。将工具坐标按原始 `Joint_tool` 变换到 `Link6` 坐标后：

- 质心距离为 **2.2905704×10⁻⁹ m**。
- 两份原始 STL 的对称最近顶点距离 RMS 为 **4.2996232×10⁻⁸ m**，最大值为 **6.8539874×10⁻⁸ m**。
- 两份 STL 各有 **2,034** 个三角面。

同一 CAD 实例、相同质量以及变换后几何和质心重合共同支持「一个物理零件导出了两份」的判断。派生模型可以保留 `Link6` 的一份物理属性与几何，将 `Link_tool` 保留为无质量的工具坐标框架。这样减少 42.787784 g，不合并为双倍质量。保留 `Link6` 是版本策略，不代表其惯量已获物理验证。

上述顶点距离用于核对两份原始导出的重合程度；它不是简化模型的表面 Hausdorff 距离，更不是接触误差或真实尺寸精度。

## 积惯量疑点仍然保留

按 URDF 矩阵元素定义组装张量，以 `R I Rᵀ` 将工具张量旋转到 `Link6` 轴方向，分别比较其自身质心处的张量。相对 Frobenius 差定义为 `||I6 - R Itool Rᵀ||F / ||I6||F`，结果 **0.2372351092**，约 **23.72%**。这里不添加平行轴项，因为比较对象均为自身质心惯量，且质心已近乎重合。

仅做诊断时，将两份张量的非对角元均反号后重算，相对差降至 **3.8498880×10⁻⁷**。这强烈提示需要核对 CAD 的积惯量输出约定或导出器坐标变换，但单个零件的数值一致性不能授权给所有连杆统一反号。原始和派生模型的符号暂时保留，等待原 CAD 质量属性与导出器实现核验。建议文档中「质量与惯性完全相同」的说法不准确：质量相同，所给张量按当前 URDF 定义变换后不一致。

## 不能从本次审计推出的结论

用户确认现有电机是达妙 4310，应以此作为现物型号信息。CSV 底座组件包含 `4310 减速电机 3D 20221104-7`，但 `Link1` 同时出现 `DM-J4340-2EC-V1.1_3d_20260325_1-1`。这暴露 CAD/BOM 与实物对应关系需要核查，不能凭 CAD 文件名反过来替换用户确认的型号。

反馈力矩的定义、单位、转子侧或减速器输出侧、传动比、控制模式及固件版本尚未核实。还需要确定实物编码器零点/正方向、真实关节限位、速度与连续/峰值力矩能力、摩擦、转子/负载惯量及质量分布。电机力矩反馈不能直接解释成末端外力，处理后模型的 7.9 N·m 也不是额定能力。

STL 本身没有可靠的长度单位声明。本项目按 URDF 的米制解释坐标；通过密度反推不能独立证实实际单位、材料及质量分布。建议文档关于电机未单独建模、质量分布均匀化、质量可能准确的判断，仍需 CAD 装配结构与实测支撑。

普通 MuJoCo mesh 碰撞使用凸包，可能填平叉形工具空腔。网格面数减少或视觉误差很小都不能证明接触几何正确。本阶段的自由空间运动学与控制测试不验证叉形工具接触、装配可达性或真实自碰撞安全。后续需要单独版本化凸分解或具有几何依据的接触代理，并明确区分仿真控制输入、外力估计与评价真值。
